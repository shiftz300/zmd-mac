## 2026-10-21：显示设置与遗留显示器记录

- 增加「显示」页：窗口化／无边框全屏启动、游戏默认分辨率、预设／自定义分辨率、读取设置窗口所在屏幕的桌面尺寸。尺寸受 macOS 缩放影响，不自动迁移游戏窗口。
- 原始游戏日志在全屏切换路径出现 `MonitorFromWindow failed`；当时会话探针枚举到句柄为 0 的 1024×768 显示器。Wine 的注册表缓存将未关联显示源的遗留记录当成虚拟屏幕；新增补丁在缓存重建时过滤此类记录。
- 新运行库隔离测试通过：两块屏幕均返回非零句柄，隐藏测试窗口分别移动到屏幕坐标后，`MonitorFromWindow` 返回正确目标。安装并重开实际官方启动器后，只读探针同样枚举到两块有效屏幕（2560×1440、1512×982），未再出现空句柄记录。
- CLI／启动脚本验证通过：分辨率校验、无边框全屏参数、恢复游戏默认时移除宽高覆盖。跨屏后游戏内全屏切换和最终渲染尺寸仍需用户实测；隔离测试不代表该项已通过。
